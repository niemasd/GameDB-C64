# GameDB-C64
Commodore 64, part of [GameDB](https://github.com/niemasd/GameDB).

## Structured Downloads
* **[`C64.data.json`](https://github.com/niemasd/GameDB-C64/releases/latest/download/C64.data.json):** All data, structured in the JSON format
* **[`C64.data.tsv`](https://github.com/niemasd/GameDB-C64/releases/latest/download/C64.data.tsv):** All data, structured in the TSV format
* **[`C64.release_dates.pdf`](https://github.com/niemasd/GameDB-C64/releases/latest/download/C64.release_dates.pdf):** Histogram of release dates, stratified by region
* **[`C64.titles.json`](https://github.com/niemasd/GameDB-C64/releases/latest/download/C64.titles.json):** Mapping of serial numbers to game titles, structured in the JSON format

# Notes

## Uniquely Identifying Games

For now, I am just using the CRC32 hash of each game to uniquely identify it. In the future, more sophisticated approaches can be discovered.
